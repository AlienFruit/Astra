# Требования для написания тестов

## Правила наименования тестов

Имя теста должно состоять из трех частей:

- Имя проверяемого метода
- Сценарий, в котором тестируется метод
- Ожидаемое поведение при вызове сценария

Шаблон имени теста: Метод_УсловиеОкружения_ОжидаемыйРезультат

Примеры имен тестов:
Constructor_OnInitialize_AddRequiredResources
GetViewBoxLinkClass_InactiveLink_ReturnDefaultClass
