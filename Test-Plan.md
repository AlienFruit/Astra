# План тестирования для проекта AlienFruit.Astra

## Введение
AlienFruit.Astra - это библиотека для ASP.NET Core, которая обеспечивает динамическую загрузку контента без перезагрузки страницы с помощью AJAX навигации и ViewBox компонентов.
